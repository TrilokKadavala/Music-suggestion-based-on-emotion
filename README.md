# Hybrid Emotion Based Music Recommendation System

## Description
This project detects human emotion using DeepFace and 
Machine Learning algorithms (RF, SVM, LR, DT, KNN).

## Features
- Emotion Detection
- Majority Voting
- Music Recommendation
- Activity Suggestion
- Image Capture
- Database Storage

## How to Run

### Training:
python train.py

### Testing:
python app.py
